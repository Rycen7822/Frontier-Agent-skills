# Recoverable writing

Use the existing task note when it can hold the recovery state. Otherwise create one note in the task's temporary workspace. Record scope and final path, useful source anchors and extracted facts, section coverage, unresolved conflicts, current draft and next action. Keep it concise and update it in place; no fixed labels or auxiliary file topology are required.

Index sources around the claims they support. Keep qualifiers, ownership decisions and reread triggers with those claims rather than copying raw excerpts or collecting a search transcript. Record decisions whose loss would cause repeated reading or conflicting revisions.

After interruption, read the note and current draft, then reopen only sources needed for the next action or affected by changes. Reuse findings whose inputs and requirements remain valid. Repository state instructions and user-requested recovery formats take precedence over this default.

Split notes or drafts only when their size or independent ownership makes one file impractical. Keep each fact in one canonical place. When the user requests an audit artifact, retain the requested source coverage and decision evidence without turning every writing task into an audit.
