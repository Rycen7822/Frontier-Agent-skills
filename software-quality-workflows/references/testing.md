# Testing ownership

Testing decisions now belong to [Test Behavior](../../test-behavior/SKILL.md). Apply it before authoring or modifying any testing, reproduction, probe, validation, verification, comparison, benchmark or smoke-check code, including temporary and inline checks. Also apply it when a behavior contract is removed or replaced, a migration completes or a compatibility obligation ends, even when no test edit is planned.

This path remains available to existing callers. Read the canonical skill for necessity, timing, independent expectations, valid execution, lifetime and retirement; keep implementation and completion decisions with SQW.
