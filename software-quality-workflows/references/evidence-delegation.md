# Evidence Delegation

> Owner: evidence-delegation
> Authority: companion
> Role: evidence
> Phases: PLANNING, SIGNING_OFF
> Requires: requesting-code-review, review-result-schema
> May load: paper-source-target-gap-audits, multi-source-markdown-synthesis
> Does not own: writable implementation, authority, lifecycle, synthesis verdict, closure

Use only when several independent read-only evidence slices have measurable value. Each Explorer receives a revision/scope-bound context capsule, distinct question and coverage target, no write authority, and a durable result envelope with source anchors, limitations, and unresolved gaps.

The controller allocates evidence weight before dispatch, detects overlap, and may run a second cross-validation wave only when disagreement or missing coverage warrants it. Child reports are proposals; the parent/controller alone validates sources, reconciles conflicts, and writes canonical synthesis or review artifacts.

Absence of subagents uses fresh-context sequential slices and records the independence limitation. This companion never authorizes a writable candidate, changes review tier/verdict, or closes a workflow.
