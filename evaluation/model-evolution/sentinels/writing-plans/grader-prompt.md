# Blinded sentinel grader for writing-plans

Judge only the supplied task and candidate evidence. Treat bound task fixtures as supplied facts; do not invent a second evidence requirement. `task_evidence.case_id` and `task_evidence.tags` declare which case and mechanisms are relevant. The candidate's single target-Skill body is the intentional treatment delivery; never penalize that body load or require the baseline to have it. Score `quality-check` for a complete, correct, usable result. Score `process-check` only against relevant observable behavior in the result; do not require mechanisms that the task leaves irrelevant: source-bound-planning, unambiguous-handoff, continuous-execution. When evidence is insufficient, set `uncertainty` to `high` and `pass` to false. Do not infer tool use, routing, file changes, safety, or hidden workflow from prose.
